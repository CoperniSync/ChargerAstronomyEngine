# STARGAZER Documentation

Stargazer is a celestial map generator that displays the approximately 30k visible stars as well as constellations, local celestial objects, and messier deep space objects, from anywhere on Earth at any time.

Stargazer began as a senior undergraduate project for the SP2025 semester at the University of Alabama in Huntsville. Originally created in the [Godot game engine](https://godotengine.org), the project has been refactored into a Unity based project. The old [documentation](https://stargazer-lcz8.onrender.com) and [repository](https://github.com/CoperniSync/Stargazer_OG) have been kept for archival purposes.


## Quick Start Notes:

1. To quickly run Stargazer, visit our [Github Repository](https://github.com/CoperniSync/Stargazer) and download the latest release.
2. To set up a dev environment, check out the "Getting Started" document.
